### 🚑 Automatic Traffic Clearance System for Ambulance
**`ESP32`** **`Machine Learning`** **`IoT`** **`Real-Time Systems`**

> An intelligent embedded system that detects an approaching ambulance and automatically clears traffic signals in its path using ESP32 and a Machine Learning model for vehicle classification.

**Key Highlights:**
- Real-time ambulance detection using ML-based classification on edge hardware
- ESP32-driven signal control logic with wireless communication
- Demonstrates integration of **Embedded Systems + AI at the Edge**
- Practical application in **smart city and automotive safety** domains

### 📡 Smart GPS Geofencing System
**`Arduino UNO`** **`Neo-6M GPS`** **`GSM Module`** **`Embedded C`**

> A location-aware embedded system that monitors asset position against a pre-defined geographic boundary and triggers SMS alerts via GSM when the boundary is breached.

**Key Highlights:**
- GPS coordinate parsing using NMEA protocol over **UART**
- Haversine formula for real-time geofence distance calculation
- GSM-based SMS alert system for remote monitoring
- Demonstrates proficiency in **Communication Protocols, Sensor Integration, and IoT**
